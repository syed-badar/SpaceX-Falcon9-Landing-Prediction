# SpaceX Falcon 9 First Stage Landing Prediction

## Project Overview
This project uses a full data science pipeline to predict the successful landing of SpaceX Falcon 9 first-stage rockets. By determining landing success, we can estimate the cost of a launch.

## Repository Structure
- **src/**: Python scripts for data collection, SQL analysis, and ML.
- **outputs/**: Interactive maps and visualizations.
- **docs/**: Final presentation PDF.

## Usage
1. Install dependencies: `pip install -r requirements.txt`
2. Run ML models: `python src/ml_predictions.py`
3. Launch Dashboard: `python src/dash_app.py`
